이번에 바뀐 것

보내주신 예약 창을 그대로 두고, 나머지를 거기에 맞췄습니다.

1. 회의실 예약 창은 손대지 않았습니다

제목 · 회의실 · 날짜 · 시간 · 빠른 시간 버튼 · 중요 회의 · 참석자 · 파란 예약 버튼까지 그대로입니다. 참석자 선택 창의 두 칸 구조와 디렉터/임직원 묶음도 그대로예요.

  • 참석자 사진은 실제 이미지를 쓸 수 없어 이름 첫 글자 원으로 대신했습니다. 실제 앱에서는 지금 쓰는 사진이 그대로 들어갑니다.
  • 중요 회의를 켜면 겹치는 예약을 뒤로 미루는 기존 동작을 그대로 흉내 냅니다.

2. 워크룸 예약 창을 같은 형식으로

  • 어떤 프로젝트 때문에 쓰는지가 첫 칸입니다. 회의 제목 자리와 같은 위치예요.
  • 날짜 · 시간 · 빠른 시간 버튼(+30분 / +1시간 / +2시간)까지 같은 구조입니다.
  • 자리 선택은 없습니다. 정원 3명만 관리하고, 누가 몇 번 자리인지는 시스템도 사람도 신경 쓰지 않습니다.
  • 그래서 시간표도 고정 세로줄을 없앴습니다. 겹치는 예약이 있을 때만 그만큼 폭을 나눠 씁니다. 아무도 없으면 한 칸을 넓게 씁니다.

3. 확인을 확실하게 바꿨습니다

전에는 체크가 장식이었습니다. 이제 항목을 다 눌러야 버튼이 켜집니다.

  • "3개 중 1개 확인"처럼 남은 개수가 보입니다. 어디를 눌러야 하는지 헤매지 않게요.
  • 누른 항목은 줄 전체가 초록으로 바뀝니다. 체크박스만 바뀌면 눈에 잘 안 들어옵니다.
  • 예약할 때와 종료할 때 각각 뜹니다. 종료 확인에는 "다음 사람이 들어올 수 있게 사용 종료를 눌러주세요"가 마지막 항목입니다.

4. 자동 테스트로 잡은 것

8명이 몰려서 예약·수정·종료하는 상황을 자동으로 돌려봤습니다. 11건이 나왔고 10건을 고쳤습니다.

  • 정원이 뚫렸습니다. 진행 중인 사람의 종료 시각을 "지금"으로 계산해서, 19시 기준으로 보면 없는 사람이 됐습니다. 19:00~20:00에 5명이 예약됐어요. 이제 예약할 때 받은 종료 시각으로 잡고 있다고 봅니다.
  • 출력 중인 프린터에 겹쳐 예약됐습니다. 같은 원인이고, 기계가 하나뿐이라 더 위험했습니다.
  • 예약 시간 전에도 사용 시작이 눌렸고, 그때 예약 시각이 덮어써졌습니다. 이제 10분 전부터만 눌리고, 예약 시각과 실제 시작 시각을 따로 남깁니다.
  • 상세에서 시작 시각을 종료 이후로 바꿀 수 있었습니다. 형식만 보고 순서는 안 봤어요.
  • 예약창에서 회의실만 바꾸고 취소해도 화면이 바뀌었습니다. 이제 확정할 때만 옮겨갑니다.
  • 종료하면 내 기록에서 빠져서 본인도 못 열었습니다.
  • 참석자를 전부 비우고도 예약이 됐습니다.
  • 내 예약이 여러 건이면 버튼이 어느 걸 가리키는지 알 수 없었습니다. 이제 사용 시작 (19:00 예약)처럼 시각을 붙입니다.
  • 고치지 않은 것 하나 — 중요 회의는 회의실 기존 기능이라 손대지 않았습니다.

5. 자정을 넘기는 출력

밤 11시에 걸어놓고 아침에 찾는 게 3D 프린터의 제일 흔한 사용법인데 막혀 있었습니다. 이제 됩니다.

  • 종료 시각을 시작보다 이르게 고르면 자동으로 다음 날로 잡습니다. 시간 아래에 몇 시간짜리인지 같이 보여줍니다.
  • 시간표에서는 자정에서 잘려 그려지고 익일 06:00까지 배지가 붙습니다.
  • 한 번에 16시간까지만 허용합니다. 실수로 하루 종일 잡는 걸 막기 위해서요.
  • 워크룸은 운영시간이 9~22시라 자정 넘김을 안 씁니다.

6. 지난 시각으로 예약하면 바로 시작

이미 자리에 앉아서 예약하는 상황이니까요. 시작 시각이 지금보다 이르면 예약과 동시에 사용 중으로 들어갑니다.

  • 따로 사용 시작을 누를 필요가 없고, 확인 창에도 그렇게 안내합니다.
  • 미래 시각으로 잡으면 예약 상태로 남고, 시간이 되면 사용 시작 버튼이 나타납니다.
  • 종료 시각까지 이미 지난 시간은 예약이 안 됩니다.

7. 가이드가 누구에게, 언제 뜨는지

실제 사이트 기준으로 노출 조건을 정했습니다. 저장은 로그인 계정에 남깁니다.

  • 첫 로그인 — 전체 가이드. 회의실·워크룸·프린터를 각각 두 스텝씩, 총 9단계로 안내합니다.
  • 하루 이상 접속 안 한 사람 — 다시 한 번 전체를 보여줍니다.
  • 이미 봤는데 새 기능이 추가됨 — 추가된 자원만 콕 집어 안내합니다. 회의실만 쓰던 사람에게 프린터가 생기면 프린터 가이드만 떠요.
  • 규칙에 자원이 하나 늘면 FEATURES 배열에 한 줄 추가로 끝. 그 자원 알림에 "새로 추가됨" 배지가 붙고 기존 사용자에게 그 부분만 안내됩니다.

8. 업데이트 알림은 자원별로 나눠서

한 알림에 몰아넣지 않고 회의실·워크룸·프린터를 각각의 알림으로 띄웁니다.

  • 알림마다 바뀐 점 서너 줄과 "가이드 보기" 버튼이 있습니다. 누르면 그 자원 가이드만 실행돼요.
  • 새로 추가된 자원 알림에는 "새로 추가됨" 파란 배지가 붙습니다.

9. 사용 기록 검색

  • 이름이나 프로젝트명으로 찾습니다. 회의실은 참석자 이름으로도 걸립니다.
  • 맞는 글자는 노랗게 강조되고, 자원 필터와 검색이 함께 걸립니다.

10. 마이페이지 (프로필 클릭)

프로필을 누르면 열립니다. 전에는 "회의실 현황 대시보드"가 개인 페이지에 있었는데, 그건 관리자가 볼 통계라 설정 중심으로 바꿨습니다. 팝업이 아니라 전체 화면으로 열리고, 뒤로가기로 예약 홈에 돌아옵니다.

  • 계정 — 이름·사진 변경, 비밀번호 변경, 이메일 변경, 로그아웃.
  • 알림 — 항목별(확정·5분 전·자동취소·자리 남) 켜고 끄기, 조용한 시간.
  • 내 예약·이용 — 다가오는 예약 수, 이번 달 노쇼 횟수, 사용 기록 바로가기.
  • 개인화 — 다크 모드, 기본으로 열 자원, 가이드 다시 보기.
  • 관리 (관리자만) — 현황 대시보드, 운영시간, 자동취소 시간, 멤버 관리. role이 admin일 때만 보입니다.

11. 20명 자동 시뮬레이션으로 잡은 것

20명이 하루 동안 마구잡이로 예약·수정·취소하는 상황을 시드를 바꿔가며 12번 돌렸습니다. 매번 정원·겹침·상태를 1분 단위로 검사했어요.

  • 빈 시각 예약 버그를 찾았습니다. 시간 선택은 10분 단위인데, 어쩌다 그 사이 값이 들어가면 셀렉트가 빈 값이 되고, 그걸 걸러내지 못해 시작·종료가 비어 있는 예약이 만들어졌습니다. 이제 형식을 검사해서 "시작·종료 시각을 모두 골라주세요"로 막습니다.
  • 그 밖에는 워크룸 정원 3명, 프린터 이중 예약, 회의실 겹침 모두 어느 시드에서도 뚫리지 않았습니다. 워크룸은 25건까지 몰려도 동시 인원이 정확히 3명에서 멈춥니다.

12. 아직 화면 안에서만 뜹니다

이 알림은 앱을 켜놨을 때만 보입니다. 앱을 닫아도 오는 진짜 알림(슬랙·폰)은 코드 지시서에서 붙여야 하고, 슬랙 사용 여부와 Firebase 요금제가 정해지면 넣습니다.
